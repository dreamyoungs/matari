# 계정 quota 주기 조회

2026-09-24: 기존 로컬 JSONL 집계에 App Server 조회를 추가한다.

- 앱 시작, 30분 간격, 수동 갱신, 잠자기 복귀 시 조회한다. 앱이 종료됐거나 Mac이
  잠든 동안의 관측을 소급 생성하지 않는다. 실패 후 자동 재시도도 30분 간격이다.
- 매분 스케줄을 확인하므로 자동 조회는 최대 약 1분 늦을 수 있다. 실행 중 중복 요청은 합친다.
- 설치된 Codex/ChatGPT 앱 내 실행 파일 또는 Homebrew의 Codex CLI가 필요하다.
  별도 API 키가 아닌 선택된 CODEX_HOME의 기존 Codex 로그인을 사용한다.
- stdio로 initialize → initialized → account/rateLimits/read만 요청한다.
  30초 제한, 취소, 응답 크기 제한을 적용하고 조회용 프로세스를 종료한다.
- 다중 버킷 응답을 우선하며 레거시 응답도 지원한다. 값이 같아도 매 성공 응답에
  새 poll 이벤트를 부여해 기존 quota_snapshots/epochs에 원자적으로 저장한다.
- 실패·잘못된 응답은 관측값을 만들지 않는다. 기존 수치와 로컬 토큰 집계는 유지하고
  UI에 별도 오류 안내를 표시한다. 로컬 로그가 없는 경우에도 조회된 quota는 표시한다.
- quota는 계정 전체, 토큰은 이 Mac만 집계한다. 여러 Mac의 동일 계정 사용을 전제로 하며
  서로 다른 계정의 이력을 분리하는 기능은 이번 범위에 포함하지 않는다.
- 기존 로컬 관측과 poll 관측은 이벤트 ID 접두사로 구분한다.

## 최근 2일 그래프

각 제한 버킷의 최근 48시간 잔여율을 제한과 토큰 합계 사이에 표시한다.
기본은 가장 긴 제한이며 여러 버킷이 있으면 `5시간 / 주간` 등의 선택 버튼을 표시한다.
요금제 변경으로 선택한 버킷이 없어지면 현재 가장 긴 제한으로 자동 대체한다.
가로축은 고정 48시간, 세로축은 0~100%다. 기존 로컬 관측과 주기 조회 기록을 함께 사용한다.
기간·요금제가 달라지거나 관측 사이가 1시간을 넘으면 선을 끊고, 마지막 관측을 현재까지
연장하지 않는다. 기록이 하나면 점만, 없으면 안내를 표시한다. 같은 기간에서는 기존
high-water 규칙으로 늦게 도착한 낮은 사용률에 의한 역행을 방지한다.
렌더링 비용을 제한하기 위해 각 30분 구간의 첫·마지막 관측을 유지하며 원본 DB는 보존한다.

## 앵커 독립창

헤더의 앵커를 누르면 동일한 뷰 모델을 사용하는 단일 floating NSPanel을 연다.
일반 창보다 위에 유지하고 헤더 드래그로 이동한다. 설정 화면에 따라 창 높이를 조정한다.
앵커를 다시 누르거나 메뉴바의 `메뉴바로 돌아가기`를 누르면 독립창을 닫는다.
고정 중 메뉴바에서는 독립창 앞으로 가져오기와 고정 해제를 제공한다.
위치는 같은 앱 실행 중에만 기억하며 재실행 시 메뉴바 모드로 시작한다.
시스템 보안 창 등 모든 창 위에 표시되는 것을 보장하지는 않는다.

근거: [공식 App Server 문서](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt).
인증 처리는 Codex가 담당하며 MATARI는 인증 토큰·계정 이메일·응답 원문을 저장하지 않는다.
