# MATARI v0.1 제품 기획

- 상태: 초안 기준선
- 최종 갱신: 2026-09-18
- 대상 플랫폼: macOS
- 제품 형태: 메뉴바 전용 유틸리티

## 1. 제품 정의

MATARI는 Codex의 현재 사용 한도 잔여량과 초기화 시각을 메뉴바에서 즉시 확인하고, 이 Mac에서 관측한 토큰 사용량과 quota 변화를 함께 보여주는 읽기 전용 모니터링 앱이다.

v0.1의 핵심 질문은 세 가지다.

1. 지금 사용 가능한 quota가 얼마나 남았는가?
2. 각 제한은 언제 초기화되는가?
3. 이 Mac에서 관측한 토큰 사용량과 quota 변화는 어떤 관계를 보이는가?

## 2. 제품 원칙

- 읽기 전용: Codex의 실행, 인증, 요청 또는 설정을 변경하지 않는다.
- 로컬 우선: 분석과 파생 데이터 저장은 기기 안에서만 수행한다.
- 관측값과 계산값 분리: Codex가 기록한 값과 MATARI가 계산한 값을 구분한다.
- 동적 제한 표시: `5시간`, `주간`을 데이터 모델에 하드코딩하지 않는다.
- 정직한 불확실성: 데이터가 부족하거나 오래되었으면 추정값 대신 상태를 표시한다.
- 작은 범위: v0.1은 현재 상태를 빠르게 확인하는 데 집중한다.

## 3. 대상 사용자

- macOS에서 Codex 데스크톱 앱 또는 CLI를 자주 사용하는 사용자
- quota가 얼마나 남았는지 반복해서 확인하는 사용자
- 토큰 소비와 quota 차감 간의 관계를 관찰하고 싶은 사용자

v0.1은 여러 기기와 여러 계정을 통합 관리하는 제품이 아니다. 두 대 이상의 Mac이나 Codex Cloud·ChatGPT Work를 함께 사용하는 경우에도, 우선 현재 Mac에서 관측한 값으로 유용한 근사치를 제공한다. 여러 기기의 관측치를 합치거나 계정 전체 사용량과 대조하는 방법은 후속 버전의 연구 과제로 둔다.

## 4. 앱 구조

### 4.1 메뉴바

여기서 메뉴바는 앱 창 안의 내비게이션이 아니라 **macOS 화면 맨 위의 시스템 메뉴바**를 뜻한다.

메뉴바 항목에는 현재 존재하는 제한 버킷의 **잔여율**만 간결하게 표시한다.

```text
63% · 27%
```

버킷이 하나뿐이면 값도 하나만 표시한다.

```text
27%
```

표시 순서는 짧은 제한 창에서 긴 제한 창 순서다. 값이 아직 없으면 퍼센트를 임의로 만들지 않고 데이터 없음 상태를 표시한다.

앱 아이콘과 메뉴바 아이콘은 별개의 자산이다.

- 앱 아이콘: Finder, 응용 프로그램 폴더, 시스템 설정, 로그인 항목 등에 표시되는 컬러 아이콘
- 메뉴바 아이콘: 약 16~18pt 환경에서 쓰는 단색 template symbol을 퍼센트 텍스트 앞에 표시

Dock 아이콘을 숨기는 메뉴바 전용 앱이어도 앱 아이콘은 필요하다.

### 4.2 클릭 패널

메뉴 목록이 아니라 SwiftUI의 정식 팝업 패널을 사용한다. 구현 방향은 `MenuBarExtra`와 `.menuBarExtraStyle(.window)` 조합이다.

예상 크기는 폭 300~340pt, 높이 350~450pt다. 내용에 따라 높이는 조정할 수 있다.

```text
Codex 사용량

5시간 제한
남음                                      63%
████████████░░░░░░
초기화                       9월 18일(금) 15:42
남은 시간                           3시간 21분

주간 제한
남음                                      27%
█████░░░░░░░░░░░░░
초기화                       9월 21일(월) 09:00
남은 시간                              2일 20시간

토큰 사용량
오늘                                    312.4M
이번 주                                  1.82B
오늘 1%당                             ≈ 39.1M
이번 주 1%당                          ≈ 41.7M

마지막 갱신                              방금 전
```

초기 버전에는 독립 메인 창과 `자세히 보기` 버튼을 두지 않는다.

### 4.3 확정된 브랜드 방향

MATARI v0.1은 **따뜻한 식물성 정밀 도구**를 시각 방향으로 삼는다.

- 모티프: 마타리꽃의 가지와 꽃송이를 데이터 포인트처럼 단순화
- 앱 아이콘: 차콜 바탕의 노란색 일곱 꽃송이 심볼
- 메뉴바 심볼: 같은 형태를 축약한 단색 다섯 꽃송이 심볼
- 브랜드 노랑: `#F6C945`
- 브랜드 차콜: `#222321`
- 진행 막대 노랑: `#D3A62A` — 브랜드 노랑보다 한 톤 어둡게 사용
- 표현 방식: 평면 색상, 그림자·그라디언트·장식 노이즈 없음
- 인상: 차분함, 정밀함, 따뜻함, 가벼운 생명력

확정 자산:

- [앱 아이콘 SVG](../design/icon-refined/matari-app-icon.svg)
- [메뉴바 심볼 SVG](../design/icon-refined/matari-menubar-symbol.svg)

아이콘의 형태와 색상은 v0.1의 기준으로 확정한다. 실제 Xcode asset catalog용 크기별 내보내기는 프로젝트 생성 단계에서 진행한다.

## 5. 정보 정의

### 5.1 제한 버킷

Codex가 제공한 제한 버킷을 그대로 모델링한다.

- 식별자
- 제한 창 길이
- 사용률 또는 잔여율
- 초기화 시각
- 관측 시각

UI 이름은 제한 창 길이를 기준으로 현지화한다.

- 300분: `5시간 제한`
- 10,080분: `주간 제한`
- 알려지지 않은 값: 해당 기간을 이해할 수 있는 일반화된 이름 또는 `기타 제한`

존재하지 않는 버킷은 `없음` 행을 만들지 않고 섹션 자체를 숨긴다.

현재 알려진 상품별 형태는 예시일 뿐 런타임 규칙으로 하드코딩하지 않는다.

- Free: 과거 월간 제한 사례가 있었음
- Plus: 5시간 및 주간 제한
- Pro: 주간 제한

상품 정책은 바뀔 수 있으므로 실제 세션에 기록된 버킷을 최우선으로 표시한다.

### 5.2 잔여율

- 메뉴바와 패널의 대표 퍼센트는 항상 **잔여율**이다.
- 원본이 `used_percent`이면 `100 - used_percent`로 계산한다.
- 0~100 범위를 벗어나거나 필드가 없으면 잘못된 값으로 처리한다.
- 원본 퍼센트 정밀도가 낮으므로 소수 정밀도를 임의로 만들어내지 않는다.

### 5.3 오늘 토큰

- 한국 시간대의 오늘 00:00부터 현재까지 이 Mac의 Codex 세션 파일에서 관측된 토큰 합계다.
- 입력, 캐시 입력, 출력, 추론 토큰을 별도 항목으로 노출하는 것은 v0.1 범위 밖이다.
- 대표값은 Codex가 기록한 `total_tokens`를 사용하되, 중복 누적을 방지해야 한다.

### 5.4 이번 주 토큰

- 한국 시간대 기준 월요일 00:00부터 현재까지 이 Mac에서 관측된 토큰 합계다.
- Codex의 주간 quota 초기화 창과 달력상의 `이번 주`는 서로 다른 개념이다.

### 5.5 `1%당 토큰`

내부적으로 장기 제한 버킷의 quota 감소량과 같은 기간의 로컬 토큰 증가량을 비교한다.

```text
관측한 로컬 토큰 증가량 / 관측한 quota 소비 퍼센트포인트
```

이 값에는 반드시 `≈`를 붙인다. 다음 이유로 정확한 환산값이 아니다.

- quota 퍼센트는 정수 단위로 기록될 수 있다.
- quota에는 다른 기기, Codex Cloud 또는 ChatGPT Work 사용량이 함께 반영될 수 있다.
- 로컬 세션 파일은 이 Mac에서 관측한 토큰만 포함한다.
- 모델, 컨텍스트, 추론, 도구 사용, 캐시 등이 실제 quota 소비에 영향을 준다.

두 대의 Mac과 웹의 ChatGPT Work를 함께 쓰는 경우 이 차이는 더 커질 수 있다. v0.1은 이를 해결된 문제처럼 보이지 않게 하면서도, 현재 Mac 한 대의 관측치가 주는 근사값을 우선 제공한다. 다중 기기 및 웹 사용량 보정은 후속 연구 과제로 남긴다.

유효한 퍼센트 감소가 아직 없거나 관측 구간이 불연속이면 `계산 중`으로 표시한다.

`오늘/이번 주 quota 사용량` 자체는 v0.1 UI에 노출하지 않는다. 계산에 필요한 변화량만 내부적으로 유지한다.

### 5.6 마지막 갱신

가장 최근에 유효한 quota 스냅샷을 관측한 시각이다. 파일 변경을 확인한 시각과 원본 이벤트 시각을 구분해 저장한다.

예시:

- `방금 전`
- `7분 전`
- `2시간 전 · Codex 비활성`

오래된 스냅샷의 퍼센트를 현재값처럼 보이지 않게 해야 한다.

## 6. 날짜와 남은 시간 표기

절대 초기화 시각은 한국어 로케일로 표시한다.

- 올해: `9월 21일(월) 09:00`
- 다른 연도: `2027년 1월 3일(일) 09:00`

상대시간은 의미 있는 상위 두 단위까지만 표시한다.

| 실제 남은 시간 | 표시 |
|---|---|
| 3일 7시간 24분 | `3일 7시간` |
| 1일 2시간 3분 | `1일 2시간` |
| 17시간 42분 | `17시간 42분` |
| 38분 12초 | `38분` |

초기화 시각이 지났지만 새 스냅샷이 없다면 100%로 추정하지 않는다. 기존 값이 오래되었다는 상태를 표시하고 다음 관측을 기다린다.

## 7. 상태와 예외 처리

### 최초 실행

- 세션 경로를 찾는 중: 로딩 상태
- 세션 파일 없음: `Codex 사용 기록을 찾을 수 없음`
- 유효한 quota 없음: 토큰 통계는 표시할 수 있지만 quota 섹션은 데이터 없음으로 처리

### 실행 중

- 일부 버킷 누락: 존재하는 버킷만 표시
- 손상되거나 미완성인 마지막 JSONL 행: 해당 행을 보류하고 다음 쓰기 후 재시도
- 파일 이동 또는 보관: 같은 세션을 중복 집계하지 않음
- 카운터 감소: 새 세션 또는 카운터 초기화로 보고 새로운 누적 구간 시작
- 장시간 변경 없음: 마지막 유효 스냅샷과 비활성 상태 표시

### 개인정보 보호

Codex 세션 파일에는 프롬프트, 답변, 도구 출력 등 민감한 내용이 포함될 수 있다. MATARI는 필요한 레코드와 숫자 필드만 읽고 다음 내용을 저장하지 않는다.

- 대화 본문
- 프롬프트와 응답
- 도구 입력과 출력
- 파일 내용
- 인증 정보

## 9. v0.1 완료 조건

다음 조건을 모두 만족하면 v0.1의 제품 범위가 완료된 것으로 본다.

1. Codex 사용 중 메뉴바의 잔여율이 새 스냅샷에 맞춰 갱신된다.
2. 제한 버킷이 하나 또는 둘일 때 UI가 자연스럽게 대응한다.
3. 초기화 절대시각과 상대시간이 정의된 규칙으로 표시된다.
4. 여러 세션이 동시에 기록돼도 토큰이 중복 집계되지 않는다.
5. 오늘과 이번 주의 경계가 한국 시간대에서 올바르게 처리된다.
6. 데이터가 없거나 오래됐거나 일부 필드가 누락돼도 잘못된 수치를 만들지 않는다.
7. 대화 내용과 인증 정보를 파생 저장소에 기록하지 않는다.
8. Codex 파일을 수정하지 않고 읽기 전용으로 동작한다.

## 10. 확정된 UX 기준

정상 화면과 예외 상태의 동작은 [MATARI v0.1 UX 상태 명세](ux-state-spec-v0.1.ko.md)를 구현 기준으로 사용한다.

- 메뉴바는 심볼과 퍼센트만 표시
- 패널 폭 336pt, 구분선형 섹션
- monospaced digit 사용
- 정상 화면에 수동 새로고침 없음
- reset 이후 새 스냅샷이 없으면 과거 퍼센트를 숨김
- 설정은 같은 메뉴바 패널 안에서 전환
- 로그인 시 자동 실행은 사용자가 선택하며 기본값은 꺼짐
- `MATARI 종료`는 footer에 유지
- VoiceOver, Reduce Motion, 라이트·다크 모드 지원
