# MATARI Community Code of Conduct

MATARI is built in public so that people can inspect, learn from, and improve it together. We want
the project's issues, pull requests, reviews, discussions, and other community spaces to remain safe
and constructive.

## Expected behavior

- Be respectful, patient, and specific.
- Critique ideas and code with evidence; do not attack people.
- Welcome questions and contributors with different experience levels and backgrounds.
- Acknowledge tradeoffs and correct mistakes openly.
- Protect local session data, credentials, account identifiers, and personal information.
- Respect maintainers' decisions about project scope, privacy, safety, and release readiness.

## Unacceptable behavior

- Harassment, discrimination, threats, stalking, or sexualized attention.
- Insults, personal attacks, trolling, or deliberately disruptive behavior.
- Publishing another person's private information without permission.
- Sharing Codex prompts, responses, tool payloads, credentials, private file paths, or account data.
- Retaliation against someone who raises a good-faith safety or conduct concern.

## Reporting and enforcement

For ordinary project disagreements, use a GitHub issue or pull request. For sensitive conduct
reports, use the private security-advisory channel described in [SECURITY.md](SECURITY.md) and mark
the report as a community-safety concern. Do not disclose private details in a public issue.

Maintainers may edit or remove content, close or lock threads, reject contributions, or temporarily
or permanently restrict participation when needed. They will consider context, impact, intent,
prior behavior, and the safety of affected people, and will keep private reports confidential to the
extent reasonably possible.

This code applies whenever someone represents MATARI or participates in a project-managed space.
